# Проверка базового подключения

Убедиться, что туннель реально несёт трафик и маршрутизация корректна.

1. Свежая сборка из `build\`, запуск, «Подключить» → UAC → Да. Статус: «Подключено».
2. **Зарубежный сайт через прокси** (главная проверка):
   ```powershell
   curl.exe -m 10 https://www.google.com   ; "exit=$LASTEXITCODE"
   ```
   Ожидание: открывается (exit 0). В логе приложения — строки `outbound/vless[proxy]: outbound connection to …`.
3. **Российский сайт**:
   ```powershell
   curl.exe -m 10 https://dobropizza.ru
   ```
   Работает и с VPN, и без.
4. **Обход RU (опционально).** Включите «Российские сайты» и «Российские IP», переподключитесь.
   Теперь рос. трафик должен идти напрямую (в логе — `outbound: direct` / не через `[proxy]`),
   зарубежный — через `[proxy]`. Так быстрее и меньше нагрузка на сервер.
5. «Отключить» → зарубежные сайты снова недоступны (провайдер), рос. работают — значит туннель снят.

**Если зарубежные не открываются при статусе «Подключено»:** проверьте лог — доходит ли
`outbound/vless[proxy]` до сервера. Если нет — проблема с сервером/профилем, а не с клиентом.
