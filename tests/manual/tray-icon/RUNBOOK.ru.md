# Проверка иконки в трее

Иконка в системном трее меняет цвет по состоянию, тултип показывает статус.

1. Запустите приложение (не подключаясь). Иконка в трее — **серая** (отключено).
   Наведите курсор — тултип «SimpleRay — Отключено».
2. Нажмите «Подключить». На короткое время — **жёлтая** (подключение), затем **зелёная**
   (подключено). Тултип показывает «SimpleRay — Подключено: …».
3. Убейте sing-box (`Stop-Process -Name sing-box -Force`): жёлтая (переподключение) →
   зелёная при восстановлении, либо **красная** при сбое.
4. «Отключить» → снова **серая**.

Цвета: серый — отключено, жёлтый — подключение/переподключение, зелёный — подключено,
красный — сбой.
