# Проверка авто-переподключения (watchdog)

Убедиться, что при крахе sing-box приложение переподключается, а при повторных неудачах —
корректно сдаётся (без бесконечного цикла).

1. Подключитесь (статус «Подключено»).
2. **Имитируйте крах движка** из PowerShell:
   ```powershell
   Stop-Process -Name sing-box -Force
   ```
3. Ожидание в логе/статусе:
   - статус меняется на «Связь потеряна — переподключение (1/5)…» и т.д.;
   - через несколько секунд восстанавливается (статус «Подключено»), если TUN поднялся;
   - зарубежный сайт снова открывается.
4. **Сдача (если реконнект не удаётся).** Если TUN не пересоздаётся (напр. завис wintun-адаптер),
   watchdog должен сделать ~5 попыток с нарастающей паузой и **остановиться** со статусом
   «Не удалось переподключиться — нажмите «Подключить»». **Бесконечного цикла быть не должно.**
5. «Подключить» вручную — повторная попытка (может потребоваться, если адаптер освободился/после перезагрузки).

**Что важно:** в логе не должно быть бесконечной череды `FATAL ... configure tun interface`
каждые ~15 секунд. Если есть — пришлите лог.
