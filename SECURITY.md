# Политика безопасности · Security Policy

SimpleRay — VPN-клиент, поэтому к безопасности здесь относятся серьёзно.
Спасибо, что помогаете делать проект надёжнее.

## Поддерживаемые версии

Исправления безопасности выходят для последнего опубликованного релиза.
Пожалуйста, обновляйтесь до актуальной версии перед тем, как сообщать о проблеме.

| Версия | Поддержка |
|--------|-----------|
| последний релиз (`releases/latest`) | ✅ |
| более старые | ❌ |

## Как сообщить об уязвимости

**Пожалуйста, не открывайте публичный Issue для уязвимостей.**

Предпочтительный путь — приватный отчёт через GitHub:
**Security → Report a vulnerability** (private vulnerability reporting).
Как запасной вариант — письмо на **inbasko@gmail.com** с темой `SimpleRay security`.

Что полезно приложить:
- версию SimpleRay и Windows;
- описание проблемы и почему это угроза;
- шаги воспроизведения (по возможности — минимальный пример);
- предполагаемое влияние.

Ответ — в течение разумного срока; после исправления авторов упоминаем в
заметках к релизу (если не попросите иначе).

> English: please use GitHub private vulnerability reporting (Security tab) or
> email inbasko@gmail.com. Do not file public issues for security problems.

## Что считается уязвимостью

- Утечка трафика мимо туннеля (traffic leak / DNS leak).
- Возможность для постороннего процесса воспользоваться туннелем.
- Раскрытие или недостаточная защита секретов (профили, ключи) на диске.
- Обход проверки подлинности/целостности обновлений.
- Внедрение кода/команд через разбор ссылок, подписок или QR.

## Модель безопасности (кратко)

- **TUN, а не локальный прокси.** Трафик идёт через виртуальный адаптер
  (wintun); открытого прокси-порта на `127.0.0.1` нет — им нельзя
  воспользоваться со стороны. Инвариант закреплён тестом `AntiLeakTests`.
- **Секреты на диске** шифруются Windows DPAPI (`ProtectedData`, привязка к
  учётной записи); запись атомарная (`File.Replace`).
- **Обновления** скачиваются только с согласия пользователя и проверяются по
  контрольной сумме **SHA256**; при неудачном запуске — откат на прежнюю версию.
